### 🔧 [mx-machinery-imports](https://github.com/aanaya-hub/mx-machinery-imports)

A two-system operations export taken apart and put back together: **1,458 rows describing 1,440
shipments**, with twenty defects found, documented and decided on. Mixed encodings, four date
formats inside one column, 1,765 ambiguous dates resolved without a single guess — and 22
shipments whose declared customs tariff code contradicts the duty actually paid, worth
**MXN 1.2 million** if the declarations are read literally.

It also publishes the things it could not conclude: no supplier ranking, because the spread
between suppliers is smaller than the uncertainty in each one.

`Python` · `pandas` · `GeoPandas` · `scikit-learn` · `SQLite` · `matplotlib`
